🔥 ออกบ่อยมาก
Attestation vs Certification ต่างกันอย่างไร? ออก 4+ ครั้ง
✅ คำตอบ
Attestation = ยืนยันว่า CI ยังมีอยู่จริง (still exist?)
Certification = ตรวจสอบ + แก้ไขค่า attribute บน CI (validate + update)
Attestation = "ของยังอยู่ไหม?" → ตอบ yes/no
Certification = "ข้อมูลถูกไหม? ถ้าไม่ถูก → แก้ด้วย"
ทั้งคู่เป็น Data Manager policy types [1] 🇹🇭 เห็น "still exist" → Attestation | เห็น "update/validate fields" → Certification
🔥 ออกบ่อยมาก
Staleness metric ใช้ field อะไร? ค่า default กี่วัน? ออก 2+ ครั้ง
✅ คำตอบ
Field = Most recent discovery (last_discovery)
Default = 30 วัน
Staleness วัดว่า CI ถูก discovery ครั้งสุดท้ายเมื่อไร — ถ้าเกิน 30 วันไม่มีใครมา discover = Stale 🇹🇭 Staleness = last_discovery = 30 days

Duplicate CI Remediator → Main CI เลือกจากเกณฑ์อะไร? (Choose 2) ออก 2+ ครั้ง
✅ คำตอบ: A + D
A. Oldest Created (สร้างก่อน = ตัวเก่าแก่ที่สุด)
D. Most Related Items (มี relationship มากสุด)
ตัวที่ถูกเลือกเป็น Main CI = แก่ที่สุด + เพื่อนมากที่สุด → เพราะเป็น record ที่ถูกอ้างอิงมากที่สุดตลอดเวลา [1] ❌ ไม่ใช่ Most Attributes, ไม่ใช่ Newest Created 🇹🇭 Main CI = Oldest + Most Related

CMDB Health Dashboard มี 3 KPIs อะไร?
✅ คำตอบ
Correctness = Duplicate, Orphan, Stale, Audit

Completeness = Required fields, Recommended fields
3C: Correctness (ถูกต้องไหม) + Compliance (ทำตามกฎไหม) + Completeness (ครบไหม) 🇹🇭 จำ 3C: Correct + Comply + Complete
